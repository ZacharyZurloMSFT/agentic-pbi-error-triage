# shots/

Screenshots referenced by `../WALKTHROUGH.html` and `../PERSONAS.html`.

See `../README.md` for the full list of expected filenames and a suggested capture workflow.

Suggested tools:

- **Windows Snipping Tool** (Win+Shift+S) for Foundry portal + SQL client captures at ~1200px.
- **Teams**: right-click card → *Copy image* or use the Teams desktop app's snip.
- **Foundry trace**: browser DevTools → Full-page screenshot for long traces.

Keep PNGs. The HTML sizes them to 100% of the figure width, so a native capture at ~1200px looks
sharp on projector-scale displays.
